# Display fonts for thumbnails

Latin-subset WOFF2 files copied unmodified from the `@fontsource/*` 5.3.0 npm packages. All are licensed under the
SIL Open Font License 1.1; each font's licence text sits next to it (`*-OFL.txt`). Used by
`src/library/overlay/Thumbnail.ts` (storyboard `thumbnail.font`) and loaded by `src/entry.ts`.

| `thumbnail.font` | Family (CSS name) | File | Feel / good for |
|---|---|---|---|
| `inter` | Inter 900 (+ 900 italic stickers) | `../Inter-Black.woff2`, `../Inter-BlackItalic.woff2` | Neutral heavy grotesk; default for science explainers |
| `anton` | Anton 400 | `Anton-Regular.woff2` | Tall condensed impact capitals; maximum headline size, news and weather |
| `bebas-neue` | Bebas Neue 400 | `BebasNeue-Regular.woff2` | Clean condensed capitals; cinematic, space, documentary |
| `archivo-black` | Archivo Black 400 | `ArchivoBlack-Regular.woff2` | Wide, very heavy grotesk; bold claims, big numbers |
| `bangers` | Bangers 400 | `Bangers-Regular.woff2` | Comic-book energy; playful, absurd or animal topics |
| `orbitron` | Orbitron 900 | `Orbitron-Black.woff2` | Geometric sci-fi; space, technology, the future |
| `playfair` | Playfair Display 900 | `PlayfairDisplay-Black.woff2` | High-contrast serif; history, culture, elegant topics |

Playfair Display carries a Reserved Font Name: the file is used unmodified, as the licence requires.
